SPOTTR iPhone glass controls and system tab bar — 2026-10-29

Reference and scope
- Inspected the local Instagram navbar recording and the 5-minute SPOTTR recording.
- User specifically wants finger tracking/drag selection, not just a timed pill animation.
- iPhone only. Existing Android and browser rendering/gestures are preserved.
- No Next.js files or external data changed. No AWS operations.

Implemented
- Native glass icon surfaces have bounded square dimensions (minimum 44pt), half-size
  corner radii, and an absolute-fill touch control. Inner flexGrow could previously
  stretch a button across its parent. Padding and minimum dimensions also disagreed
  with the original radius on smaller buttons.
- Auth Back/Close is icon-only and 48x48 on iOS, including the non-glass fallback.
- Removed glass from labeled Back actions in dashboard event editing, account lists,
  Friends, Legal, checkout return and the ordinary public-profile header.
- Replaced iOS SF Symbol action artwork with consistent stroke icons. Navbar artwork
  has consistent 26pt outline/selected forms and white foregrounds.
- Added a local Apple-only Expo module, SpottrNativeTabs. It embeds a real
  UITabBarController with four icon-only items and delegates completed selections to
  existing React Navigation/role routing. UIKit owns touch tracking and animations;
  no custom PanResponder or emulated drag physics were added.
- Each native control belongs to its screen, not a global window overlay. Empty
  controller content does not intercept touches above the tab bar. React route
  changes don't recreate items in the mounted control. Programmatic selection is
  guarded against emitting user navigation. Acknowledgements restore a selection
  when JS navigation is prevented.
- Pink selection is requested through UITabBarAppearance.selectionIndicatorTintColor.
  No private UIKit subview access, gesture replacements or haptic generators.
- Missing local module / unsupported Liquid Glass runtime uses the existing navbar.
